# ToneryMaxim AI Sales Assistant V3 – iba zmenené súbory

Tento ZIP neobsahuje celý projekt, iba súbory ktoré boli doplnené alebo upravené.

## Postup

1. Rozbaľ ZIP do koreňa projektu.
2. Povoľ prepísanie existujúcich súborov.
3. Spusti:

```bash
npm run build
npm run dev
```
